## 🌟 مميزات الموقع (Features)

- 🌐 **دعم كامل للغتين (العربية والإنجليزية)**: تبديل فوري بضغطة زر مع ضبط كامل لاتجاه الصفحة (`RTL` و `LTR`).
- 🌙 **الوضع الليلي والنهاري (Dark & Light Mode)**: ثيم عصري مريح للعين مع حفظ تفضيل الزائر تلقائياً في المتصفح.
- ⚡ **أداء فائق وسرعة صاروخية**: بدون أي مكتبات خارجية ثقيلة (Pure Vanilla HTML, CSS & JavaScript).
- 📱 **متجاوب 100% (Fully Responsive)**: تجربة مثالية على شاشات الهواتف والأجهزة اللوحية والحواسيب.
- 💻 **أقسام متكاملة لطالب حاسبات**:
  - **قسم رئيسي تفاعلي (Hero)**: مع محاكاة لكتابة الكود البرمجي (Typing Effect).
  - **شريط المهارات المتحرك (Animated Band)**.
  - **نبذة عني (About)**.
  - **المهارات والتقنيات (Skills & Technologies)**.
  - **مجالات الاهتمام والتركيز الأكاديمي (Areas of Focus)**.
  - **المشاريع والتطبيقات البرمجية (Projects & Labs)**.
  - **مسار التعلم والإصدارات (Learning Journey Timeline)**.
  - **روابط التواصل (Contact Links)**: واتساب، والبريد الإلكتروني مع زر عائم (FAB).

## 🚀 كيفية رفع وتشغيل الموقع مجاناً على GitHub Pages

### الطريقة الأولى (الأسهل والأسرع - عبر المتصفح في دقيقة واحدة):
1. ادخل على حسابك في [GitHub](https://github.com) وسجل الدخول.
2. اضغط على الزر الأخضر **New** لإنشاء مستودع جديد (Repository).
3. سمّ المستودع بأي اسم تريده، مثلاً: `portfolio` أو `omar-zeyad`.
4. اجعل المستودع **Public** ثم اضغط **Create repository**.
5. اضغط على **uploading an existing file**، واسحب ملف `index.html` و `README.md` وأفلتهما في الصفحة، ثم اضغط **Commit changes**.
6. من القائمة العلوية في المستودع:
   - اذهب إلى **Settings** ⚙️.
   - من القائمة الجانبية اختر **Pages**.
   - تحت قسم **Build and deployment**، اختر الفرع **main** أو **master** واضغط **Save**.
7. انتظر دقيقة واحدة، وسيعطيك GitHub رابط موقعك المباشر مجاناً:
   `https://<your-username>.github.io/<repository-name>/`
